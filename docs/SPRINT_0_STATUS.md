## Commands to finish Sprint 0 on the development machine

Use Node 20+ and the repository-pinned pnpm 9.7.0:

```bash
corepack enable
corepack prepare pnpm@9.7.0 --activate
pnpm --version
pnpm install
```

Then run the quality checks:

```bash
pnpm lint
pnpm typecheck
pnpm test:unit
```

Start Docker Desktop, then run the migration baseline check (it uses its own Compose project and port 55432):

```bash
pnpm verify:migration
```

Review and commit the generated `packages/db/prisma/migrations/` directory. Then run the integration suite and web build against the dedicated test services/environment:

```bash
pnpm test:integration
pnpm --filter @ultra/web build
```

Do not run integration tests against production data. Do not replace the isolated migration cleanup with an unqualified `docker compose down -v`.
